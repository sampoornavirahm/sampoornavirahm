# New project card template

Copy this section into the **B2C Product Lab** area of your profile README when you have a real project to showcase. Replace every bracketed field and remove anything that does not apply.

```markdown
### [Project name]

<sub>[CATEGORY] · [CURRENT STATUS] · [YEAR]</sub>

[One or two sentences explaining what it does, who it is for and the problem it addresses.]

**What I built / contributed**
- [Product decisions, requirements or user research]
- [UX, architecture or implementation contribution]
- [Testing, deployment or learning]

**Built with**: `Tool / technology` `Tool / technology` `Tool / technology`

**Status:** [Exploring / Prototype / Testing / Released / Paused]

[Source code](https://github.com/...) · [Live demo](https://...) · [Case study](https://...)

![Project screenshot](assets/[project-screenshot].png)
```

## Example of how to fill it in

The following is a format example only. Replace it with your own real project details before publishing; do not leave this example in the public profile.

```markdown
### PantryPal

<sub>FOOD & LIFESTYLE · PROTOTYPE · 2027</sub>

A small personal pantry tracker that helps people keep track of ingredients and plan meals around what they already have.

**What I built / contributed**
- Defined the first-use flow and core user journey.
- Designed the pantry and recipe screens.
- Built and tested the initial prototype with AI-assisted development.

**Built with**: `React` `Firebase`

**Status:** Prototype

[Source code](https://github.com/your-username/pantrypal) · [Live demo](https://example.com)
```
