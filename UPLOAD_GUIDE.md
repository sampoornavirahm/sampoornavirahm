## Steps

1. Download and extract `Piyush_Patil_GitHub_Profile_Package.zip`.
2. Open `https://github.com/sampoornavirahm/sampoornavirahm`.
3. Replace the repository's existing `README.md` with the new `README.md` from this package.
4. Upload `PROJECT_CARD_TEMPLATE.md` and the complete `assets` folder. Keep the folder and filenames unchanged; the README uses relative image paths.
5. Commit the changes to the default branch and refresh your GitHub profile.
